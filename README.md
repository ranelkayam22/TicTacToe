# Tic Tac Toe

A simple Tic Tac Toe game written in Python.

## Features

- Two-player gameplay
- Win detection
- Tie detection
- Input validation
- Console-based interface

## Technologies

- Python 3

## How to Run

```bash
python Ex2.py
```
